# 契衡合同管理系统 · 接口一览

> 面向二次开发/接口调试。所有接口前缀 `/api/v1`，返回 JSON。前端单页应用就在同一个 jar 里（`static/`），无需跨域配置。

---

## 一、认证与调用约定

1. `GET /api/v1/health` —— 公共健康检查，返回 `{"status":"UP","name":"契衡合同管理系统"}`。
2. `GET /api/v1/auth/csrf` —— 获取 CSRF Cookie（`Set-Cookie`）。
3. `POST /api/v1/auth/login` —— 登录，成功后服务端下发会话 Cookie。
4. 之后所有**写请求**（POST/PUT/PATCH/DELETE）都要带 `X-CSRF-Token` 请求头（值取自 CSRF Cookie），并携带会话 Cookie。
5. 会话失效返回 `401`，权限不足返回 `403`。

会话 Cookie 默认 `HttpOnly`；HTTPS 部署时设 `SECURE_COOKIE=true` 让它带 `Secure` 属性。

错误返回统一格式：

```json
{ "error": "FIELD_VALIDATION_FAILED", "message": "请检查填写内容", "details": { "amount": "金额格式不正确" }, "request_id": "..." }
```

其中 `message` 是给人看的中文提示，`details` 只在字段级校验（`422`）时出现，`request_id` 可用于查日志与审计。生产配置下**不会**返回堆栈。

## 二、认证与账号

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/health` | 公共 | 存活检查 |
| GET | `/auth/csrf` | 公共 | 取 CSRF 令牌 |
| POST | `/auth/login` | 公共 | 登录（限速：账户 10 次/15 分钟、来源 50 次/15 分钟） |
| GET | `/auth/me` | 登录 | 当前用户、角色、是否必须先改密 |
| POST | `/auth/logout` | 登录 | 退出 |
| POST | `/auth/change-password` | 登录 | 修改密码（≥6 位，弱密码黑名单，不能与旧密码相同） |
| GET | `/users` | 管理员 | 账号列表 |
| POST | `/users` | 管理员 | 新增账号（可自动生成临时密码） |
| PATCH | `/users/{id}` | 管理员 | 改姓名/角色/启用停用 |
| POST | `/users/{id}/reset-password` | 管理员 | 重置密码（返回临时密码，下次登录强制改密） |
| DELETE | `/users/{id}` | 管理员 | 删除账号（不能删最后一个管理员） |

**首个管理员只能用命令行创建**（无 HTTP 入口）：`java -jar ContractHub-1.0.0.jar --init-admin --username=… --display-name=… --password=…`；忘记密码用 `--recover-admin`。

## 六、字段配置结构（`field_schema`）

```json
{
  "schema_version": 1,
  "groups": [{ "key": "base", "label": "合同信息", "order": 1 }],
  "fields": [
    {
      "key": "amount_incl_tax",        // 必须与母版里的 {{amount_incl_tax}} 同名
      "label": "含税总金额（元）",
      "type": "money",                 // text|textarea|date|money|integer|select|boolean|computed
      "group": "base",
      "order": 1,
      "required": true,
      "binding": "amount_incl_tax",    // 必须等于 key 或 null
      "scale": 2, "min": "0.00", "max": "999999999.99",
      "default": "1000000.00"          // 可选：新建合同时预填
    },
    {
      "key": "amount_upper", "label": "人民币大写金额", "type": "computed",
      "calculator": "rmb_upper", "source": "amount_incl_tax"   // source 必须是一个 money 字段
    }
  ]
}
```

约束（保存时校验）：`1 ≤ 字段数 ≤ 150`；`key` 满足 `^[a-z][a-z0-9_]{0,63}$` 且唯一；`binding` 等于 `key` 或 `null`；`group` 必须已在 `groups` 中声明；金额必须两位小数；`computed` 只支持 `rmb_upper`；日期字段可用 `after` 引用另一个日期字段做先后校验。

**母版是字段的唯一来源**：母版里的每个 `{{key}}` 都必须有对应字段，字段里每个非空 `binding` 的 key 也都必须出现在母版里，否则 `validate`/`publish` 报 `BINDING_MISMATCH`。

## 七、主要错误码

| 码 | HTTP | 含义与处理 |
| --- | --- | --- |
| `UNAUTHENTICATED` / `SESSION_EXPIRED` / `SESSION_REVOKED` | 401 | 未登录或会话失效，重新登录 |
| `CSRF_INVALID` | 403 | 缺少/错误 `X-CSRF-Token` |
| `FORBIDDEN` / `PASSWORD_CHANGE_REQUIRED` | 403 | 权限不足；或首次登录未改密 |
| `WRONG_PASSWORD` / `WEAK_PASSWORD` / `SAME_PASSWORD` | 401/422 | 密码错误 / 太弱 / 与旧密码相同 |
| `NOT_FOUND` | 404 | 对象不存在或无权访问（不区分，避免泄露） |
| `EDIT_CONFLICT` | 409 | `expected_lock_version` 过期（别人改过了），刷新后重试 |
| `CONTRACT_STATE_CONFLICT` / `CONTRACT_FROZEN` / `CONTRACT_NOT_FINALIZED` | 409 | 当前状态不允许该操作 |
| `TEMPLATE_OUTDATED` / `TEMPLATE_DISABLED` / `TEMPLATE_UNPUBLISHED` | 409 | 模板已更新/停用/未发布，先升级或联系维护员 |
| `IMMUTABLE_VERSION` / `VERSION_ORDER` / `VERSION_IN_USE` | 409 | 已发布版本不可改；版本号顺序；版本被引用 |
| `TEMPLATE_IN_USE` | 409 | 模板被合同引用，不能删除（改用停用） |
| `PREVIEW_REQUIRED` / `REVIEW_OUTDATED` / `TEST_OUTDATED` / `TEST_REVIEW_REQUIRED` | 422/409 | 必须先完整查看 PDF / 确认已过期 / 需重新试填 |
| `FIELD_VALIDATION_FAILED` | 422 | 字段校验失败，看 `details` |
| `BINDING_MISMATCH` / `NO_PLACEHOLDER` / `INVALID_SCHEMA` | 422 | 字段配置与母版不一致 / 母版没有占位符 / 配置本身不合法 |
| `COMPLEX_TABLE` / `SPLIT_RUN_STYLE` / `UNSUPPORTED_PLACEHOLDER` / `UNSUPPORTED_STRUCTURE` / `UNKNOWN_TOKEN` | 422 | 母版结构不被支持（见模板维护指南） |
| `UNSAFE_DOCX` / `EXTERNAL_LINK` / `INVALID_DOCX` / `MIME_MISMATCH` / `ZIP_LIMIT` / `PDF_LIMIT` | 415/422 | 上传文件不安全、类型不符或超限 |
| `CONVERTER_UNAVAILABLE` / `CONVERSION_FAILED` / `CONVERSION_TIMEOUT` | 任务错误 | LibreOffice 缺失或转换失败/超时 |
| `QUEUE_FULL` | 429 | 生成队列满，稍后重试 |
| `LAST_ADMIN` / `USERNAME_TAKEN` / `INVALID_ROLE` | 422/409 | 账号相关约束 |
