# 契衡合同管理系统 · 使用手册（业务人员）

> 面向使用系统起草合同的同事。管理员/维护员的模板制作请看 [模板维护指南.md](模板维护指南.md)。

---

## 一、登录

1. 浏览器打开系统地址（本机 `http://127.0.0.1:8080/`，局域网问管理员要 IP）。
2. 输入账号与密码。第一次登录会用**管理员发的临时密码**，系统会强制你先改密码（新密码至少 6 位，不能是常见弱密码）。
3. 忘记密码找管理员重置（重置后会再次要求首次改密）。

## 三、起草一份合同

### 1. 新建
工作台或「我的合同」→ **新建合同** → 填写合同名称、选择模板 → **创建并开始填报**。

> 模板下拉里只出现"已启用且有当前发布版本"的模板。看不到想要的模板，找管理员确认模板是否已发布/启用。

### 2. 填报

- 表单按字段类型渲染：文本框、多行文本、日期选择器、金额、整数、下拉选择、（自动计算的金额大写只读）。
- **必填**字段名后带 `*`；没填就生成会被拦下，并汇总提示"还有 N 项信息未填写"。
- 金额按十进制填写（如 `1000000.00`，最多两位小数）；整数只能是整数。
- 日期用选择器选择，写进合同会自动变成"2025年9月1日"这种中文格式。
- 金额大写（如"人民币大写金额"）由系统按来源金额字段自动生成，不用手填。
- 同一字段在合同里出现多处时（例如交货地点出现 3 次、双方落款日期 2 处），填一次全部生效。

### 3. 保存

- 点 **保存草稿** 会立即保存并刷新页面。
- **关闭填报页（点弹窗外面、按 Esc、点关闭）时，只要改过内容，系统会先自动保存为草稿再关闭**，并提示"已自动保存为草稿"。所以不小心点到空白处不会白填。
- 如果自动保存失败（例如金额格式不对、或别的窗口也在改同一份合同），页面**不会关闭**，错误会显示在顶部，你可以改好再关。

### 4. 生成与定稿（四步）

| 步骤 | 按钮 | 说明 |
| --- | --- | --- |
| 1 | **生成全文预览** | 先把当前表单存成草稿，再排队生成 Word/PDF（后台转换，通常几秒到十几秒） |
| 2 | **查看全文 PDF** | 必须在浏览器里完整打开本次生成的 PDF——这是"确认全文"的依据 |
| 3 | **确认全文并定稿** | 生成后 30 分钟内有效；改动过母版/表单需要重新生成再确认 |
| 4 | **下载 Word / PDF** | 定稿后可下载正式文件 |

> 生成任务在后台跑，页面会轮询状态。若提示"内容未变，已复用上次生成的全文"，说明表单没变化，系统复用了同一份快照——这是正常的，不会重复生成。

### 5. 定稿之后

| 操作 | 说明 |
| --- | --- |
| **下载 Word / PDF** | 定稿版本的文件（不可变） |
| **登记已签署** | 线下签字盖章后上传扫描件归档，可填签署日期与备注；传错了可以**作废**该签署件再传 |
| **作废合同** | 需要填写作废原因；作废后保留全部历史（修订、文件、审计），合同不可再修改 |
| **派生新草稿** | 以这份合同为模板新建一份草稿（内容带过去，可再改），适合续签/类似合同 |
| **升级到 Vx** | 模板发布了新版本时出现；会把现有填报数据按新版本的字段配置迁移过来 |
| **彻底删除** | 见下方"删除规则"，**不可恢复** |

## 四、合同状态与"现在能做什么"

| 状态 | 能做什么 |
| --- | --- |
| **填报中**（草稿） | 改表单、保存、生成、查看 PDF、确认定稿；可派生？否；可作废？否；可**彻底删除**（本人或管理员） |
| **已定稿** | 下载 Word/PDF、登记已签署、作废、派生新草稿；**不能改表单** |
| **已签署** | 下载、作废、派生；签署件可补传/作废 |
| **已作废** | 查看历史、派生新草稿；**仅管理员**可彻底删除 |

## 五、常见提示的含义

| 提示 | 含义与处理 |
| --- | --- |
| 还有 N 项信息未填写，请补全后再生成 | 有必填项为空，按提示的字段名补齐 |
| 金额格式不正确 / 须在 0.00～999999999.99 之间 | 金额只能数字、最多两位小数、不能为负 |
| 日期不得早于起始日期 | 结束日期早于开始日期了 |
| 内容已被其他窗口修改，请保留当前输入并刷新后重试 | 同一份合同在别处被改过（比如另一个标签页）；记下你的内容，刷新后重填 |
| 模板已更新，请先升级合同 | 模板发布了新版本，先点「升级到 Vx」再生成 |
| 请先打开本次生成的完整 PDF | 确认定稿前必须先在浏览器里完整查看过 PDF |
| 母版或字段已变更，请重新试填 | （维护员会看到）模板母版/字段改过了，试填确认失效 |
| 429 登录失败次数过多 | 触发限速（默认 10 次/15 分钟），等一会儿再试或联系管理员 |

## 六、注意事项

- **定稿后不能改内容**：确需修改请派生新草稿（或作废后派生），不要试图改已定稿文件。
- **彻底删除不可恢复**：只保留审计记录（谁在什么时候删了什么、原因）。草稿本人可删；**已作废只有管理员能删**。
- 合同编号由系统自动生成，形如 `HT-2026-000001`；如果模板里有"合同编号"字段，把系统显示的编号填进去保持一致即可。
- 下载的文件名带编号与版本信息，便于归档检索。
- 表格、金额、日期这些关键信息，定稿前**务必在"查看全文 PDF"里逐项核对**。
